# Runtime Gates

## Authority

- A fresh matter completes with task and step tables absent.
- Production selection does not call bridge projection or read TaskSnapshot.
- Every decision is persisted before prompt or effect.
- Production calls typed transition validation.

## State And Prompt

- Intake, inspect, act, verify, recover, wait, and report render materially
  different state, context, tool, grammar, and exit cards.
- Decision fingerprints bind all prompt and admission surfaces.

## Completion

- Readiness-only, initialization-only, plan-only, and immediate finish outputs
  cannot close an imperative goal.
- Every action has one admission.
- Required effects, observations, artifacts, and checks exist before response.

## Continuity

- A long artifact uses more than four useful decisions and completes.
- Same failure cannot repeat with the same strategy tuple.
- A failed native tool cannot remain an Ok attempt or render fault=ok.
- Edge-blocked work selects wait or report, not idle.
- Crash resume neither duplicates effects nor loses obligations.

## Referential Integrity

- Every observation references one existing accepted admission.
- Every accepted admission has one prepared effect and one terminal outcome.
- Rejected admissions have no external effect.

## Quiescence

- No synthetic closed matter represents daemon idle.
- Quiescence occurs only with no eligible work or due wake.
