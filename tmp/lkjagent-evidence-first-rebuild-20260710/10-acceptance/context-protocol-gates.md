# Context And Protocol Gates

## Context

- Total and per-lane budgets are actually enforced.
- Selection is stable across shuffled candidate insertion.
- No semantic claim appears twice across prompt regions.
- Every excerpt has a current resolvable source fingerprint.
- Material conflicts block only dependent operations.
- Raw harness JSON, unrequested structured-file blobs, secret-bearing, failed,
  and untrusted instruction bodies are excluded from normal prompts.
- Explicitly needed structured source is represented by source-linked path/value
  cards or a bounded inert excerpt when exact syntax is necessary, and
  round-trips through typed patch tools.

## Tools

- Table-driven state matrix exposes only allowed tools and hidden reasons.
- Ordinary views contain one to four tools unless an explicit exploration state
  proves a broader need.
- Shell is hidden when a native tool suffices.
- The model never sees the global catalog.

## Protocol

- Attribute-free grammar covers every adopted tool and content envelope.
- Invalid XML, attributes, JSON, stale decisions, duplicate fields, bad values,
  path escapes, hidden tools, and repeats are rejected before effects.
- Every parsed action has exactly one admission.
- Real endpoint first-pass and repair metrics meet the adopted threshold.

## Recovery

Format repair uses current decision values and a bounded diagnosis. Output-limit
repair splits or continues a semantic unit instead of repeating the impossible
call.
