# Documentation Forensics

## Useful Structure

The docs tree is short, linked, and machine-oriented. Current-state separates
target, claimed proof, and gaps. Those patterns should remain.

## Truth Problems

- Current-state says four standard endpoint profiles closed, but raw databases
  show blocked work and synthetic idle replacement.
- Docs say state-selected prompt behavior, while context is selected before the
  state decision and prompt cards are persisted after rendering.
- Docs say the state ledger is the control plane, while selection still depends
  on task and step snapshots.
- Docs describe one workbench renderer, but TTY and line modes use separate
  state, reduction, window, and rendering paths.
- Transitional engine and bridge pages remain prominent and invite continued
  investment in the retired authority.
- Numeric prompt-profile suffixes remain in code and proof even though the
  project rejects release-style names.

## Required Practice

Current-state must list raw contradictions as open gaps until fresh behavioral
evidence closes them. A docs claim needs an owning source symbol, focused test,
and final-commit evidence path. Old plan packets must not remain discoverable as
current instructions.
