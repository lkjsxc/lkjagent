# Scenario Matrix

## Personal

- decompose a mixed "review journal, TODO, calendar" request into distinct
  intents instead of storing the command as one TODO;
- Japanese diary composition from same-day evidence;
- explicit journal capture and same-day merge;
- TODO create, update, waiting, and completion;
- calendar with relative date normalization;
- finance entry, semantic month, and summary;
- note capture and later recall;
- contradiction between old and corrected owner fact.

## Projects

- create two projects and retrieve only the named one;
- inspect a repository and summarize source-linked findings;
- edit Rust files, run focused and broad checks, and report diff;
- resume a project matter after daemon restart;
- organize project notes without changing source prose.

## Artifacts

- long world-history reading material under small output caps;
- nested report with semantic sections and manifest;
- revise one section and invalidate dependent checks;
- no response-path success before final bytes exist.

## Protocol And Recovery

- malformed XML, stale decision, hidden tool, duplicate field;
- endpoint timeout, output limit, connection failure;
- filesystem conflict and crash at each write phase;
- repeated no-progress action;
- material context conflict.

## TUI

- duplicate logical sources, tied timestamps, streaming draft, restart;
- Japanese input during a slow call;
- resize, manual scroll, bottom follow, and more than forty messages.
