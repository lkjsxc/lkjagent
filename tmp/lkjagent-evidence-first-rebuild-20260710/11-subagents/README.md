# Subagents

## Purpose

Provide bounded parallel roles with explicit inputs and outputs.

## Roles

- docs-cartographer.md
- runtime-engineer.md
- store-workspace-engineer.md
- context-engineer.md
- protocol-engineer.md
- tui-engineer.md
- evaluation-operator.md
- independent-verifier.md

## Common Contract

Read owning docs first. Inspect current source and raw evidence. Do not create
unused scaffolds. Return base commit, node ID, owned and inspected files, patch
or findings, exact commands and exit codes, raw evidence paths, unresolved
faults, interface changes, risks, and next executable action. A subagent's
status is not acceptance.
