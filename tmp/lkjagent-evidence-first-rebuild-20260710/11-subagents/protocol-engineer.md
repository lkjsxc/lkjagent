# Protocol Engineer

## Objective

Raise correct tool-call rate while keeping model exchange attribute-free and
non-JSON.

## Work

- compare name/value and direct-field action grammars;
- strict typed parser faults and decision binding;
- state-derived small tool views and hidden reasons;
- native tool contracts and bounded observations;
- endpoint grammar capability probe;
- typed format, admission, and semantic repair;
- removal of special finish and broad default tool catalog.

## Tests

Every tool, Japanese and multiline fields, XML entities, truncation, stale
decisions, unknown or duplicate fields, path escape, bad primitives, repeat
guard, recovery, and exact admission count.

## Output

Report first-pass, repair, wrong-tool, accidental-close, token, latency, and
goal metrics. Adopt one grammar path and delete unused product alternatives.
