# Context Engineer

## Objective

Build decision-specific, budgeted, contradiction-safe context.

## Work

- state-derived information needs and source routing;
- body and metadata candidate discovery;
- exact and near deduplication across prompt regions;
- temporal contradiction model and dependency blocking;
- cost-aware lane selection;
- source validation and external edit handling;
- matter capsules and invalidation;
- stable-prefix layout and telemetry.

## Tests

Ten-thousand-item shuffled selection, Japanese token estimates, source changes,
material and unrelated conflicts, contamination, secret redaction, semantic
duplicate absence, actual budget enforcement, and cache-stable ordering.

## Output

Run the context combination matrix and recommend adoption from task outcomes.
Retain evidence for rejected combinations.
