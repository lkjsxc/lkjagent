# Docs Cartographer

## Objective

Make docs the unambiguous current map before implementation.

## Work

- map every behavior claim to source and tests;
- identify bridge, task, step, template, demo, and false-proof text;
- rewrite current-state from raw database and Git evidence;
- design the native matters, operations, workspace, context, protocol, TUI, and
  evaluation tree;
- delete superseded pages and repair links;
- keep each page concise and single-owner.

## Output

Produce a docs-only commit, contract-to-source gap table, removed-page list, and
the first implementation dependency. Run docs, links, topology, line, naming,
and reachability gates.

## Do Not

Do not claim implementation, preserve historical alternatives in current docs,
or mark gaps closed from old run summaries.
