# Protocol Experiments

## Factors

- current name/value arguments versus direct field tags;
- schema only versus schema plus one concrete example;
- unconstrained output versus endpoint grammar;
- one, two, and four visible tools;
- fixed harness-selected path versus model-selected path;
- generic parse repair versus typed repair;
- stable tool-card prefix versus volatile ordering.

## Corpus

Exercise every native tool with Japanese, multiline text, XML entities, long
paths, stale decisions, unknown fields, duplicate fields, range faults,
placeholder-like values, truncation, and tool-view mismatch.

## Live Scenarios

Use personal capture, project inspection, code edit, long artifact, and injected
recovery. Repeat each combination with fresh data and a fixed scenario seed.

## Adoption Metrics

Measure first-pass parse and admission, repair success, wrong-tool rate,
accidental completion, calls per useful effect, tokens, latency, and final goal
success. Retain results for rejected and conditionally useful combinations.
