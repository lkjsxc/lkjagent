# State Program Matrix

## Normative Projection

The selected decision chooses exactly one row. Tool names are further narrowed
by intent and focus; a listed set is a maximum family, never an instruction to
show every member. `effect-ready` and `observe` are harness phases and make no
model call.

| Prompt state | Context emphasis | Maximum tool family | Envelope | Recovery input | Exit predicate |
|---|---|---|---|---|---|
| intake | current owner turn, active policy, candidate matters | none | question or message | classification ambiguity | one matter and explicit obligations exist |
| frame | objective, owner constraints, exact known refs | context_inspect, workspace_search | action or question | missing required input | operation graph has feasible current candidates |
| inspect | named project/record, causal evidence, expected check | read, search, tree, Git reads | action | stale/missing source | required source fingerprints are current |
| plan | obligation coverage, dependencies, budgets | operation_split, operation_replan | action | infeasible unit or dependency | executable semantic units and checks exist |
| action-select | current target, content constraints, minimal sources | one admitted effect family | action or content | parse or admission fault | one complete action is accepted or content is admitted |
| effect-ready | no prompt | no model tools | none | prepared-effect reconciliation | effect reaches one durable outcome |
| observe | no prompt | no model tools | none | contamination or missing lineage | one bounded observation and state event commit |
| verify | fresh artifact/document refs and check parameters | check_run, workspace_validate, verify_run | action | measured check fault | every current required predicate has fresh evidence |
| recover | one failure lineage, last good source, next ladder step | one repair tool or narrowed effect family | action or content | named fault only | causal condition changes or explicit wait/block commits |
| wait-owner | exact blocking reason and already known facts | none | question | malformed owner answer | answer event satisfies the missing input |
| wait-external | wake condition and preserved partial work | none | message | due wake or external change | due time/event makes an operation eligible |
| report | verified outputs, current paths, residual risk | none | message | message persistence fault | report postconditions and close transaction commit |

## Compilation Assertions

For every row, persist state keys, information needs, selected source IDs, lane
caps, tool-view fingerprint, envelope grammar fingerprint, recovery policy,
budget, and exit predicate before rendering. A table-driven test enumerates all
intent and focus combinations, asserts hidden-tool reasons, and proves at least
two rendered surfaces differ whenever the state changes materially.

## Invalid Combinations

Report cannot expose mutation. Verify cannot write owner content. Recover cannot
render unrelated history. Wait cannot have an executable current operation.
Action-select cannot own a prepared effect; effect-ready cannot lack an accepted
effectful admission. A question cannot close a matter, and a message cannot
satisfy an effect or check obligation.
