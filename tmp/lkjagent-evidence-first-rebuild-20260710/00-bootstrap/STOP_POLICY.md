# Stop Policy

## Permitted Final Stop

The primary agent may hand off only when all conditions hold:

- all released workgraph nodes have mechanically bound receipts and the final
  gate independently recomputes every required product predicate;
- the worktree is clean;
- docs describe the final behavior and no retired contract remains;
- focused, integration, clean-checkout, Docker, live endpoint, and PTY gates
  test the final source commit;
- repeated live sessions contain real scheduled goals throughout the time box;
- raw SQLite agrees with every summary;
- no required matter is blocked, pending, active, or falsely closed;
- the independent verifier exits zero.

## Permitted Blocked Stop

A blocked handoff is allowed only when new owner authority is genuinely required
and no safe in-scope task remains. It must name the exact blocker, failed
command, raw evidence, affected workgraph nodes, and the first command to run
after resolution.

## Forbidden Stops

- one slice or one test passed;
- code compiles;
- a local Docker run passed while clean CI is unproven;
- the daemon is running but useful work ended;
- the model said ready, finished, or complete;
- a live loop consumed 900 seconds mostly in idle;
- historical or skipped evidence exists;
- the editable progress report looks complete.
