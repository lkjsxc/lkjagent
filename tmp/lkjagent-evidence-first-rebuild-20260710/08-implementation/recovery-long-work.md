# Recovery And Long Work

## Task A: Failure Lineage

Persist normalized signature, tried strategy, changed condition, next strategy,
budgets, and wake time. Count only failures in the same operation lineage.

## Task B: Strategy Reducer

Implement typed ladders for parse, admission, endpoint, output limit, effect,
check, context conflict, no progress, and crash interruption.

## Task C: Feasibility

Before dispatch, estimate target output and context cost. Reject duplicate output
paths and impossible word/token combinations. Convert large work into semantic
units.

## Task D: Partial Output

Keep truncated output as quarantined recovery evidence. Resume only from a
validated safe boundary or regenerate a bounded unit. Never treat truncated
bytes as a completed artifact.

## Task E: Progress Detection

Compute obligation, artifact, evidence, uncertainty, strategy, and dependency
deltas. Repeated zero progress forces inspect, split, replan, clarify, or
suspend.

## Task F: Waiting And Wake

Represent owner questions, endpoint backoff, scheduled retries, and filesystem
conditions explicitly. A blocked edge cannot fall through to idle.

## Task G: Long Artifact Regression

Complete the world-history request across semantic files or sections under
configured budgets. Verify final bytes and source links, then produce a path-
linked response.
