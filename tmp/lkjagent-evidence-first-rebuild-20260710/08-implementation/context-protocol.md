# Context And Protocol

## Task A: Decision-First Context

Move context preparation after state selection. Derive information needs and
lane caps from the selected operation. Persist candidate and exclusion reasons.

## Task B: Budgeted Selection

Implement cost-aware deterministic selection, cross-region deduplication,
relevance sorting, source validation, and actual budget spending. Add shuffled
10,000-item tests.

## Task C: Conflicts

Normalize temporal claims, create dependency-specific blocking edges, and add
inspect, deterministic resolve, and owner-question operations.

## Task D: Prompt Program

Compile stable kernel, policy, state, objective, context, recovery, tools, and
grammar cards from the decision. Reject JSON-like harness bodies and duplicate
semantic claims. Permit a bounded project JSON excerpt only when the active
obligation requires its syntax; mark it inert and bind it to a source path and
fingerprint.

## Task E: Tool Views

Derive small tool sets from state and evidence need. Persist hidden reasons.
Remove special finish and broad default exploration.

## Task F: Grammar Trial

Implement direct-field and current name/value parsers behind an experiment
switch. Probe endpoint grammar capability. Run full tool corpus and live cells.
Adopt the measured winner and delete the loser from product code.

## Task G: Observations

Return compact attribute-free observation cards. Store raw safe output outside
normal context and quarantine failed or secret-bearing output.
