# Evaluation And Closeout

## Task A: Acceptance Runner

Replace elapsed-loop profiles with scenario definitions containing scheduled
turns, expected obligations, negative predicates, and raw evidence capture.

## Task B: Comparative Trials

Run several context, grammar, tool-view, recovery, and planning combinations.
Use at least three repeats per meaningful cell. Record all results, including
rejected and conditional combinations.

## Task C: Daily Use

Run three or more fifteen-minute sessions on final source. Schedule meaningful
owner goals throughout. Include life records and recall, multiple projects,
long artifact, injected faults, and PTY interaction.

## Task D: Truth Audit

Read each run database and workspace independently. Compare matter state,
obligations, checks, artifacts, messages, metrics, and summary. Fail any
disagreement.

## Task E: Cleanup

Delete bridge source, old current instructions, redundant plan packets from the
active docs map, anonymous fragment generation, canned record content, and
unused TUI paths. Keep redacted failure fixtures and decision evidence.

## Task F: Final Gates

Freeze source, rerun focused tests, quiet verification, clean archive, Docker,
live campaigns, PTY, packet acceptance, docs truth, and public CI. Any later
source change restarts this task.
