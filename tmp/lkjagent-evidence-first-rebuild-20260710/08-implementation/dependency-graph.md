# Dependency Graph

## Serial Spine

The executable source of dependency truth is `00-bootstrap/workgraph.xml`.
Its bounded spine is baseline capture, docs authority, repository and evaluation
foundations, native store and reducer, production cutover, integrated adoption,
docs reconciliation, source freeze, parallel live and PTY proof, evidence
commit, public CI, and finally mechanical acceptance outside the graph.

## Parallel Windows

After docs authority:

- repository determinism and evaluation harness may proceed in parallel;
- event reducer and workspace transaction slices follow the shared store and may
  proceed in parallel;
- context selection and protocol parser experiments may proceed in parallel;
- TUI transcript work proceeds beside recovery after shared store contracts;
- evaluation tooling begins early with failing fixtures, then follows every slice.

## Merge Barriers

- no app switch before state/store contracts pass;
- no prompt switch before decision-first ordering exists;
- no live campaign before clean deterministic gates pass;
- no cleanup before comparison fixtures preserve old failures;
- no final evidence before source freeze.
- no final verification before live, PTY, evidence commit, and public CI finish.
