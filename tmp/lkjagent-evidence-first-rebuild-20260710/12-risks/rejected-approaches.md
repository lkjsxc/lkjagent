# Rejected Approaches

## Editable Self-Check Completion

Rejected because prior agents checked every box while raw live databases showed
blocked matters. Use anchored machine gates and independent verification.

## More Prompt Prose Without Authority Change

Rejected because current state labels append policy lines after a task-step
decision. State must select context, tools, grammar, recovery, and exit behavior.

## Increase Retry Count

Rejected because an impossible 1,500-word request with a 768-token cap will fail
more expensively. Recovery must change feasibility or strategy.

## Global Tool Catalog

Rejected because it increases format errors and irrelevant actions. Derive a
small view from persisted state.

## Eager Workspace Scaffold

Rejected because empty generic directories and READMEs look like work while
containing no owner information. Create navigation beside real content.

## Elapsed Idle As Live Proof

Rejected because thousands of synthetic idle snapshots hid blocked tasks. Use
scheduled scenarios and raw matter predicates.

## Text-Based TUI Deduplication

Rejected because identical valid messages may differ and logical duplicates may
have different source IDs. Persist canonical logical message identity.

## One-Shot Long Content

Rejected because output caps discard useful partial work. Use semantic bounded
units and verified assembly.
