# Historical Prose Trial

## Purpose

Record archived prose-stress evidence without making it a current product
contract.

## Archive State

This file is archaeology. The recorded runs helped expose endpoint timeout,
resume, artifact, and verification issues, but they are not the active proof
path and are excluded from normal prompts, default profiles, and completion
claims.

## Preserved Lessons

- Long-running generation needs durable prompt frames, exchange refs, and token
  usage rows.
- Artifact writes need fingerprints and small checked units.
- A live attempt that stops at a time box is evidence, not success.
- Historical raw data can seed deterministic fixtures only after redaction and
  minimization.

## Current Replacement

Daily-use profiles in [live-proof.md](live-proof.md) and deterministic corpus
entries in [benchmarks.md](benchmarks.md) are the current evaluation path.
Structured artifacts, command transcripts, workspace manifests, reports, and
TUI transcripts replace the old prose-stress target.

## Failure This Prevents

Historical stress data remains auditable without reintroducing it as a default
owner goal, prompt target, or proof requirement.
